Bắt đầu nhanh

Tạo dự án đầu tiên chỉ với một mô tả. Mở velcli.dev, chọn Tạo ứng dụng mới và nhập yêu cầu.

Tạo một trang web portfolio với Next.js và Tailwind

Các lệnh và ví dụ trong tài liệu này mang tính minh họa. Hãy đối chiếu với mã nguồn trong repository trước khi phát hành.

AI Agent

Agent lập kế hoạch, tạo và sửa file, chạy build rồi báo kết quả. Bạn có thể xem trước (Preview) hoặc mở mã nguồn để chỉnh tiếp.

Workspace

Explorer, Editor và Terminal nằm chung một màn hình, tối ưu cho điện thoại.

npm install
npm run dev

VelclawHost

Chọn tên dự án và nhánh (ví dụ main), bấm Deploy. Hệ thống chạy ba bước: Build, Deploy, Live.

VelcliHub

Kho template và cộng đồng: Next.js Blog, AI Chatbot, Portfolio. Chọn template rồi deploy ngay.

Plugins

Mở rộng tính năng: GitHub Integration, Vercel Deployment, Database (PostgreSQL / MongoDB), AI Models (OpenAI / Gemini / Groq).
